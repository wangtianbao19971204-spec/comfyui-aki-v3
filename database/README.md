# 数据库结构与隔离样例

此目录管理三套现有 SQLite 库的纯结构基线、虚构测试数据和未来迁移的登记入口；不是另一份生产资料库，也不实现尚未定义的新数据库业务。

- `schema/v1/`：来自已验收 SQL 快照的 17 张表、11 个显式索引和 24 个触发器，不含任何生产数据行。
- `fixtures/`：少量虚构中性数据，覆盖分类、词条、收藏/历史、目录关联和修订触发器。
- `contract.json`：源 SQL 摘要、相对运行位置、DDL 内容哈希、规范结构指纹和 fixture 行数。
- `migrations/index.json`：版本 `0001_baseline_20261005` 的明确登记；后续迁移需要新文件和专项执行器，不能覆盖此基线。
- `tools/contract.py`：结构检查、源 SQL 复核、全新隔离目录初始化和只读验收。

具体用法及未来数据库修改流程见 [数据库维护约定](../docs/DATABASE.md)。完整真实资料仍保留在 `snapshot/library/`，本目录不会替换或缩减它。
