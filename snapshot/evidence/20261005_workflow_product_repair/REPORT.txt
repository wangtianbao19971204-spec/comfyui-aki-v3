二、工作流正确性与维护安全

1. 修复 A1 / A29 两套共 8 处阶段对比的接线和名字：
   基础 → 手脚后 → 区域后 → 脸后 → 眼后；眼后 → 最终交付的第五组保留。
   标题现在对应真实比较阶段，不会再把倒序或跨阶段差异误当作某个部件的效果。
2. 校正 10 个节点的 24 处陈旧 widgets_values_named 镜像。
   修复的是描述镜像，实际 force_inpaint / feather / 缝补参数等未改变。
3. 清理 Anima 二放误写 K2、旧主采样建议、旧交叉二采、种子模式等说明。
   “二放”明确写为分块二放（1.5×，可选），不是承诺 2× 或 ComfyUI 核心原生算法。
4. 正式 UAP v2 模板成为默认构建源；独立旧工作流明确只是历史快照，不承诺双向同步。
5. merge_unified_workflow.py 的 --validate 现在只读。
   无参数拒绝写入；导出必须显式指定全新候选文件；拒绝覆盖正式目录、模板或已有候选。
   从旧独立源重建需显式 --legacy-sources，仍只能生成新候选。

三、模型、提示词与运行范围

1. 根据本地 17 个模型文件的张量键与层数建立已核验配套清单。
   原版 Anima / Anima 2.9B / Krea2 分族，下拉禁用跨族或未核验选项。
   提交检查底模、编码器文件、编码器 type、VAE；扩图旧 LLLite 标记补齐。
   2.9B 的原版 LLLite 控制仍禁用。故意错配扩图模型时，提交前拒绝。
   这是静态清单，不是提交时重读文件头，也不防止同名文件被事后替换。
2. 提示词写入目标沿真实连线分成“生成输入”和“草稿·需采用”，生成输入排前。
   三个无下游的草稿明确需要采用到主输入；反推追加正向只列真实生成目标。
3. ComfyUI 顶部通用运行与常用台运行，统一定向当前图像任务：
   最终预览、保存、相连收尾及已开启的 SW-10V 阶段对比。
   在线反推节点仍可存在于序列化图里，但不在本次执行目标或其依赖闭包中。
   显式反推任务的 queueNodeIds 不改写；非 UAP 图不受影响。
4. 新增“运行当前图像任务”。只有匹配的入队回执才显示“已加入队列”。
   拦截/失败不再显示含糊的“请求已处理”。

四、细化与二放交互

1. 常用台可直接改原子图的检测阈值、裁剪上下文、局部降噪、局部种子与种子模式；
   二放可改最终倍率、降噪和独立种子。高级采样、缝补等仍保留在原节点。
2. 面板顺序与执行顺序一致：手 → 脚 → 区域标准/快速 → 脸 → 眼。
3. 参数与原控件是同一份值：浏览器把手部降噪改为 0.29 后，真实导出也是 0.29；
   测试后恢复 0.30。编辑关闭部件不会自动启用它。非法阈值 2 被拒绝。
4. 种子和种子模式使用整行空间；修掉主题 CSS 覆盖造成的极窄输入框。
   1280×720 下 16 位种子完整显示，字段宽约 309px。
5. 状态区分关闭、处理中、缓存复用、执行结束/中断；补上 execution_interrupted。
   不把“执行结束”解释为检测命中，也不推测命中数或实际重绘数。

五、界面整理

1. 常用台自动收成一行导航，1280×720 下内容起点从审计时约 y=267 提前到 y=181.6。
2. 进入手部子图，父 UAP 导航自动隐藏；通过原生面包屑返回后恢复。
3. 完整工作台宽屏保持参数/结果左右布局；窄屏提供“参数与输入 / 结果与状态”切换。
   760×900 下结果区顶部约 y=538，底部约 y=729，首屏可见，无整页横向溢出。
   原审计版本的结果区初始位置约 y=3633；两者是不同页面状态下的布局测量，不是性能基准。
4. LoRA 四栏统一为角色/姿势、基础/修复、风格/补充、汇合/追加。
5. 指令编辑使用“编辑指令”；抠图与纯超分隐藏无关的提示词检查卡。
6. 深浅主题与搜索 Escape 做了小范围回归，未宣称覆盖物理中文输入法、所有主题或触屏。

七、明确未做与剩余边界

本轮真实 GPU 提交 0；无在线模型调用、上传、清队列、释放显存或服务重启。
历史 Anima 局部重绘与 Krea2 四个中性样例的有限画质验收仍可追溯，但不是本轮重跑。
没有本轮成人区域画质测试，也不保证多人、遮挡、小部位、不同画风或新 LoRA 的命中率与改善幅度。
新底模/编码器/VAE 需要更新核验清单；清单匹配不保证 LoRA 兼容性与画质。
命中/重绘数没有上游事件支持，当前不会显示虚构统计。
重复 SAM loader 的实际成本、主画布大范围重排、低价值孤立节点和历史模板归档保持为后续候选；
未为“清理”擅自删除历史资源或改变用户现有工作流。

八、如何使用与回滚

先保存你自己的未保存编辑，再打开全新 ComfyUI 页面，重新载入：
G:\ComfyUI-aki-v3\ComfyUI\user\default\workflows\UAP统一生产工作台_v2.json
旧页面可能仍运行缓存模块，单纯打开工作台不代表已载入这轮代码。
细化与二放仍由你按需勾选，不会默认打开。

回滚脚本：同目录 release.py。
只读检查：python\python.exe <本目录>\release.py rollback-check
实际回滚：python\python.exe <本目录>\release.py rollback
本轮 dry run 已通过，未执行回滚。
回滚只恢复本轮 12 文件，保留上一轮 Krea2 修复；拒绝后续文件漂移、忙队列或服务身份变化。
新增 refinement_controls.js 会在实际回滚时精确删除，candidate 副本仍保留。
before/、baseline.json、release_manifest.json 是最初回滚依据，未覆盖。
若今后真的回滚，还需把父 STATE / CONTINUATION 切回对应版本，不能保留本轮“已发布”的状态指针。

当前最新入口已更新到父 STATE.json 与 CONTINUATION.txt；历史 runs 保留。
