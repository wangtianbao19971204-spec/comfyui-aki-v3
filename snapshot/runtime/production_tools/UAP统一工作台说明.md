# UAP 统一生产工作台

当前入口：`ComfyUI/user/default/workflows/UAP统一生产工作台_v2.json`。

2026-09-07 的进一步精简直接更新这个文件。三套主生产流和六套扩展仍在同一画布中，通过顶部导航浏览；各模型的生成链保持独立。

## 常用操作

打开后默认进入 Anima 原版的“日常总控”，显示集中编辑面板。正负提示词、出图模式、四路 LoRA 选择及强度、工具和细化组件开关、尺寸、种子、采样参数放在同一块。三个主分支使用相同布局；Krea2 另有文生、图生、遮罩三项降噪。空 LoRA 栏仅占一行搜索框，添加后显示条目、启用勾选和强度。

面板直接修改原节点。LoRA 从本地列表选择后按“+”添加，“×”移除；长列表内部滚动。尺寸提供方图、竖图和横图快捷值。修改后通过 ComfyUI 工作流菜单保存；生成使用现有运行按钮。

“原节点 ↗”或开关旁的“↗”可收起面板并定位详细工具，“常用控制台”随时返回。查看未启用分支时面板只读，启用该分支后可编辑，避免误开另一条生产链。收起面板时，画布里的 LoRA 组与工具总开关也已安排到日常区，位于提示词、尺寸和输出区下方。

顶部“浏览工作分支”选择目标，再点击“启用此分支”进行切换。浏览和定位只改变视图。启用分支时，原分支关闭，新分支恢复它上次保留的可选与旁路状态；首次使用恢复原始生产模板的状态。状态文字显示当前由此导航启用的分支。不要另用外层分组的手动静音操作切换分支，以免绕过状态管理。

主分支导航依次提供：

1. 日常总控：集中编辑面板；原节点分两排摆放，包含提示词、尺寸采样、输出、LoRA 和工具开关。
2. 参考与反推：输入图片、PixAI Tagger v1.0、在线反推和 JoyCaption。
3. 提示词工具：文本整理、标签组合、图库与模板。
4. 模型配置：模型编码器和模型说明。LoRA 与总开关已归入日常总控。
5. 控制与修复：编码、参考预处理、控制图和输入模式。
6. 细化与二放：细化组件和原生放大。
7. 阶段对比：结果对照和中间预览。

阶段按钮默认定位到第一个小组。“当前阶段操作区”可直达具体工具，“上一步 / 下一步”按分组顺序遍历，跨阶段同步更新高亮。“分支全览”看整体关系，“回到日常操作”返回入口。“收起导航”保留分支选择和启用状态，减少遮挡。

扩展分支按参考输入、提示词、模型、处理、交付组织。它们独立运行，先准备各自的输入图与参数。

## 布局约定

- 节点按内容定尺寸：参数节点通常宽 240–360，文本结果框 320×100，主要提示词 420×230，常用最终预览 360×320。图库为 760×580，模板目标为 480×360；浏览器可按控件实际最小尺寸校正。长文本和列表使用内部滚动。
- LoRA 空列表从最低 200 高改为 32 高；空堆叠节点为 400×200，加载节点为 400×220。添加条目时节点按内容增高，列表最高 164 后内部滚动，同时自动顺移下方节点和分组；清空条目后缩回。此行为仅用于带紧凑标记的 UAP 节点。
- 节点标题与组标题单独预留空间；组内边距 16，节点水平间隔 24，竖向间隔另加 30 的标题空间。同阶段组间距 48；阶段列宽按实际内容计算。
- 模型加载与 LoRA 组合分成相邻小组；SW / FX 可选组保持原有成员，开关只匹配当前分支的后缀。
- 日常操作置顶，尺寸和种子与采样解码分两列，短部件共享列空间；辅助区分三列按阶段向下排列。主模型的布局结构一致。
- 导航按浏览器 CSS 视口计算缩放和偏移，落点位于导航栏下方。

已有 QGN 罗盘继续保留。快捷键在画布获得焦点时使用，输入框中不会触发。主模型键定位日常提示词小组，扩展键定位输入小组；顶部导航同步显示对应分支。

| 1 | 总控说明 |
| 2 / 3 / 4 | Anima 原版 / Anima 2.9B / Krea2 |
