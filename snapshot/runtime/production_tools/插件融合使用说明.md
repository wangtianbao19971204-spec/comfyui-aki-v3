# UAP：LoRA Manager、WeiLin 与 Anima 协同使用

更新：2026-09-07。入口为现有 `UAP统一生产工作台_v2` 的「常用控制台」。

## 日常操作

1. 在导航中启用要使用的分支，再进入「日常总控」。仅浏览其他分支时，常用控制台不可编辑。
2. 在需要的 LoRA 栏点击「浏览器」。浏览器底部会显示分支和具体栏位，例如「Anima 原版生产 / 风格 / 补充 LoRA」。Anima 原版和 2.9B 默认进入 `anima`，Krea2 默认进入 `krea2`，包含子目录。
3. 在 LoRA Manager 卡片点击纸飞机，追加到绑定栏位；Shift+点击替换该栏。替换会采用传入的强度和启用状态。追加保留已有条目的强度、开关和锁定状态。
4. 提示词可直接在控制台修改，也可点击「WeiLin 编辑」进入原编辑器。编辑结果回写同一个原节点。
5. 要使用共享预设，先选择「正向」或「负向」，再点击「共享预设」。预设库显示实际目标，点击「插入」只追加到该输入。重复插入相同完整词串不会叠加；不对权重、括号等提示词语法做拆分重写。
6. 点击「Anima 角色 / 服装 / 姿势 / 背景」打开当前分支的原生选择器。具体入口按该分支已有节点显示。勾选旁边的「启用标签组」才让该组参与生成；它与右侧「快捷标签创意拼接」是同一个开关。
7. 回到控制台检查尺寸、种子和采样参数，按平时的 ComfyUI 运行按钮生成。

## 三个插件如何分工

| 内容 | 管理位置 | 工作流中的写入位置 |
|---|---|---|
| 模型预览、搜索、收藏、元数据、配方 | LoRA Manager 浏览器 | 从控制台打开时绑定的一个 LoRA 栏 |
| 正向文本、标签编辑、原有随机模板 | WeiLin 编辑器 | 现有 WeiLin 提示词节点 |
| 共用提示词条目与分类 | WeiLin 共享预设库 | 选定的正向/负向输入；Anima 通过现有适配器读取 |
| 角色、服装、姿势、背景选择 | Anima 原生选择器 | 各自标签节点，沿现有连线汇入提示词 |

共用词库继续使用 WeiLin 的 `user_data/prompt_selector`。保留 Anima 已有的读取、分类、去重、缓存失效和「同步 WeiLin」机制。本次没有复制第二套词库，也没有迁移收藏、预设或模型文件。

生产工作流继续使用现有 LoRA Manager 堆叠与加载链。三个插件各自的节点、JSON 格式和原生 LoRA 界面保留；本次统一的是常用入口、共享词库与明确的写入目标，没有把不同加载器的状态自动相互复制。

## 兼容行为

- 绑定的浏览器页在工作流重载、更换或目标停用后拒绝写入。请从目标栏重新点击「浏览器」，会复用 LoRA Manager 窗口并更新绑定。
- 普通 LoRA Manager 入口仍可选择节点；UAP 不再提供同时写入多个 LoRA 栏的选项，避免同一条链重复加载。桌面广播在 UAP 中只接受唯一启用的最终加载器。
- LoRA 浏览器与配方页之间跳转保留目标绑定。
- 本地快捷添加读取 LoRA Manager 当前的 `legacy` / `full` 语法设置。完整路径模式保留目录；旧语法模式遇到跨目录同名文件会提示处理，不再任取第一个文件。修改语法设置后点击控制台「刷新」。
- 模型强度与 CLIP 强度可以不同，CLIP 强度 0 会保留。
- LoRA 浏览器发来更新时，控制台刷新对应列表，避免输入框仍显示旧强度。
- 共享预设库只按需加载自己的脚本；首次打开 WeiLin 编辑器才加载完整编辑器资源。并发打开等待同一个加载过程。
- 共享预设库原有的全局入口及编辑器内部入口保留原行为；要指定写入 UAP 的正向/负向输入，使用常用控制台入口。

目录预选用于缩小浏览范围，不替代 LoRA 与基础模型架构的兼容性判断。本次没有执行模型推理，也没有验证每个模型文件的出图效果。

若系统没有 `node`，本机验证使用的是 `C:/Users/Administrator/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`。

回退插件改动时，按 `before/` 的相对路径恢复相应文件，并移除本轮新增的 `web/comfyui/workflow_targets.js` 与 `static/js/utils/workflowTarget.js`；随后刷新 ComfyUI 和 LoRA Manager 页面。不要用测试快照覆盖日常工作流。`before_workflow.json` 只用于本次验证时恢复原值，后续产生个人修改后不能直接覆盖回退。

插件升级可能覆盖这些本地前端改动。升级后应复核本文的目标绑定、共享库单实例加载和同名替换三条交互路径。
