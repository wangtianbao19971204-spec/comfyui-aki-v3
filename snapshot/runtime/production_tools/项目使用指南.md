# 统一工作台使用指南

日常入口是 `ComfyUI/user/default/workflows/UAP统一生产工作台_v2.json`。它把三条主生产链和六条图片处理链放在一个项目里，各分支保留自己的提示词、模型、参数与输入图片。

## 一次完整操作

1. 从左上方打开常用控制台。需要大面积浏览资料和结果时，进入统一工作台。
2. 选择工作分支，确认“运行分支”。浏览另一分支不等于启用；使用“启用并切换”明确切换。
3. 根据任务选择生图、提示词反推或提示词优化。右侧显示该任务的输入、状态与结果，运行按钮对应当前任务。
4. 在左侧调整当前分支的提示词、模型、LoRA 和参数。需要参考图片的流程，先检查右侧输入图片。
5. 资料库可以单独浏览；需要写入时，先确认底部“使用到”的字段和正负方向。已禁用、被连线控制或已失效的目标不能写入。
6. 执行一次，检查结果。通过 ComfyUI 的保存操作保存工作流；界面参数会同步原节点，个人副本仍由你保存。

## 选哪条分支

| 分支 | 适合的工作 | 主要输入 | 与其他分支的区别 |
|---|---|---|---|
| 01 Anima 原版 | 动漫生成、已有 LoRA 与控制链 | 提示词；图生图时加参考图 | 现有原版 LLLite 控制权重在这条链使用 |
| 02 Anima 2.9B | 2.9B 动漫生成与细化 | 提示词；需要时加参考图 | 模型与 LoRA 要匹配 2.9B；现有原版 LLLite 权重不通用 |
| 03 Krea2 | Krea2 文生图、图生图、遮罩修改 | 提示词、对应模式的图片 | 使用 Krea2 模型与该链的降噪设置 |
| 04 Krea2 指令编辑 | 根据自然语言修改已有图片 | 输入图片 + 编辑指令 | 正向内容是编辑指令，使用编辑模型 |
| 05 Anima 2.9 裁剪精修回贴 | 修改图片局部并放回原位 | 图片、裁剪范围、提示词 | 需要先确定裁剪区域；坐标和回贴尺寸影响结果 |
| 06 透明素材 | 抠图并保存透明 PNG | 输入图片 | 不需要正负提示词；使用抠图模型 |
| 07 Anima 原版左右扩图 | 保留中心并补全左右画面 | 图片、提示词、扩展边距 | 使用原版 Anima 的扩图控制链 |
| 08 二倍交付 | 输出为原图二倍尺寸 | 输入图片、超分模型 | 超分后缩为目标倍数 |
| 09 四倍素材 | 输出为原图四倍尺寸 | 输入图片、超分模型 | 输出尺寸更大，显存与时间需求随尺寸上升 |

这些流程共用资料库、写入方式、界面主题、分支切换和任务结果区；模型架构、编码器、输入图片、控制模块与输出目标各自独立。模型下拉列表表示本机可选文件，不代表任意模型都能跨架构替换。

2026-09-29 已修复维护入口里失效的 `Anima/anima_baseV10.safetensors`：UAP v2、套件 01、扩展 07 及对应模板改用本机的 `Anima/animayume_v15Base.safetensors`。它是同属原版 28 层架构的另一模型，画风可能变化，并非同一文件改名。旧文件已备份；个人历史推荐流和 UAP v1 没有自动替换。

## 两种工作方式

**常用控制台**用于快速调提示词、LoRA 和参数，同时保留画布空间。**统一工作台**提供完整资料库、模型管理与较大的任务结果区。

进入资料库会展开完整工作台。用“返回常用控制台”回到小面板；“关闭工作台”结束本次完整工作台浏览。两种方式下，点击“原节点 ↗”或工具旁的定位入口都会收起遮挡并定位画布。

工作区内的“选择其他工作流 ↗”使用 ComfyUI 原有的工作流列表。独立 `生产套件_*.json`、`生产扩展_*.json` 仍保留，适合单条链处理；不会自动覆盖个人工作流。

## 资料和提示词

- 角色、服装、姿势、画师等入口按用途筛选。卡片预览用于浏览参考，正文才是写入目标的内容。
- “待用列表”适合先收集多条内容，再检查正负向和权重后使用。
- `/library` 用于共享资料补全；普通词典和模型补全沿用原有设置。
- 只有能可靠判定的字段才自动标注正负向。方向不明确时需要在界面明确选择；说明节点不再作为提示词写入目标。
- 写入后可以使用“撤销本次写入”。若切换了工作流或原字段被改动，旧撤销不会覆盖新内容。
- 某条资料没有源图，与已有图加载失败是两种状态。没有源图的内容仍可阅读和使用；不把占位图当成已经生成的预览。

## 运行与结果

“开始生图”只提交当前分支的图片交付目标及必要的清理节点；“开始反推”只提交所选反推工具的结果目标。当前分支没有相应工具或输出时，界面会提示原因。

右侧结果按当前工作流、分支和任务筛选。停止操作针对当时正在运行的任务；等待队列和其他任务通过 ComfyUI 原生队列管理。在线反推沿用你配置的服务，执行时可能使用对应服务额度。

“提示词优化”使用提示词助手当前选定的扩写服务、模型和规则。先读取字段或粘贴独立草稿，再点击“开始优化”；只有此时才发送草稿。结果先预览，可复制，或确认替换所选字段并撤销。独立草稿只提供复制。切换任务、页面、工作流或关闭工作台会取消本次优化，过期结果不能写回。优化服务与生图队列分别控制；此入口不提交整张工作流。

同一浏览器页面内，关闭并重开同一工作流、同一分支可恢复优化草稿文本；不会恢复旧写入目标或请求。草稿只在内存暂存，刷新页面前请复制需要保留的内容。

## 外观

顶部提供白天、夜间、多色三种配色，使用同一套插画与部件布局。画布底色、网格和原生菜单可以随主题联动；已有节点的功能配色保留。

在“设置 → 显示与浏览”关闭“画布、菜单随工作台主题切换”，即可恢复联动前的原生配色。多色主题沿用当前明暗，因此可以在白天或夜间基础上切入多色。

## 启动与维护

当前两轮验收使用你从绘世启动的完整插件环境。根目录 `启动_ComfyUI_生产.cmd` 是另一个可选的24插件生产配置，不能把它的历史收据当作当前绘世实例状态。Anima、Krea2、轻量入口用于指定流程；轻量配置不包含完整工作台界面。不要同时把两个后端启动在8188，也不为整理文档切换现有启动方式。

生产资料、图库、数据库和模型原位保留。旧恢复快照迁入 `_archives/2026-09-28_workflow_cleanup` 后，应通过其中的清单和恢复工具还原，再使用对应历史恢复脚本。

维护资料入口见同目录的 [资源维护入口](资源维护入口.md)。本轮实现、服务验收和未完成的验收边界，以 `benchmark_reports/2026-09-28_workflow_ui/overnight_optimization/WORK_PLAN.md` 及相邻收据为准。浏览器连接错误不等于 ComfyUI 后端停止；以服务检查结果分别判断。
