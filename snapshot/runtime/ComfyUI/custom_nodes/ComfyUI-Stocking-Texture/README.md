# ComfyUI 丝袜纹理

在已完成的插画上添加细线、针织、线圈、斜单线、加濑风或试验油光纹理。新增“丝袜纹理 · 完整编辑器”，接入原版 SAM 点选、像素笔刷、预设、PSD 和实时预览。原有两节点工作流继续支持批量和外接软蒙版；不加载扩散模型。

核心算法与完整界面来自 [silvermoong/stocking-texture-tool](https://github.com/silvermoong/stocking-texture-tool)，固定来源与 SHA 见 [UPSTREAM.json](UPSTREAM.json)，保留 [MIT 许可](LICENSE)。使用现有 ComfyUI 服务，无额外监听端口、自动安装或模型下载。

## 完整编辑器

1. 搜索“丝袜纹理 · 完整编辑器”，接入单张 IMAGE，运行一次，再点“打开完整编辑器”。也可以不接图，直接打开 PNG/JPG/PSD。
2. 点选部位并切换 SAM 小／中／大候选，用画笔／橡皮修边，每个部位画至少一条横纹走向线。支持部位拆分／吸附／合并、镜像走向、手动隔开线、擦除自动墙和撤销重做。
3. 在“纹理”页选择六样式，调整密度／强度／亮点及可选摩尔纹，保存、覆盖或载入预设。整体分屏与 100%／200% 细节实时更新，可标出问题；载入预设可撤销。
4. 点“应用到节点”，关闭编辑器，再运行得到成品、仅丝袜透明图层、图层透明度和问题标记。成品可接 `SaveImage`。

编辑自动存为草稿，只有“应用到节点”写入工作流。工作流保存参数、笔画和压缩蒙版；原图、深度是 `input/stocking_studio/assets` 内 SHA256 命名的不可变素材。迁移工作流时一并带上素材目录，或导出引导 PSD。预设、草稿、导出在当前 ComfyUI 用户的 `stocking_texture` 目录。

选区完成后在 100% 检查完整袜体、袜口、足部和交叉遮挡处，分别标注两腿并修掉衣物／背景误选。局部多边形只能用来检查算法，不能当作完整成品。油光尤其依赖真实轮廓与走向，错误的直线分区会形成不自然接缝。

当前来源为上游 `f74c8ac`，包含作者新增的摩尔纹和新版油光。摩尔纹默认关闭；开启后可调强度和面积，需要内置或外接深度，缺深度时会明确提示并阻止导出／执行。旧工作流未保存这些参数时保持关闭。新版油光沿求解器识别的遮挡连接延续高光。

导出通过浏览器下载成品 PNG、仅丝袜透明 PNG、丝袜引导 PSD。重开 PSD 可恢复原图、部位、走向、隔开线和手绘“亮点”层；纹理参数另存预设／工作流。支持中英切换。完整编辑器单图处理，最多 2400 万像素、32 部位、24 MiB 编辑数据，同时最多 4 个编辑器。改变输入或工作流后，旧编辑器会阻止过期数据覆盖。

## SAM 与内置深度

使用当前 ComfyUI Python 安装 `requirements.txt` 依赖，权重只从本地读取。来源、固定版本、SHA256 见 [MODEL_SOURCES.json](MODEL_SOURCES.json)：

- SAM ViT-B：`models/sams/sam_vit_b_01ec64.pth`。
- Depth Anything V2 Small HF：`models/stocking_texture/Depth-Anything-V2-Small-hf/`，含 `config.json`、`preprocessor_config.json`、`model.safetensors`。

支持 extra_model_paths 中 `sams`、`stocking_texture` 分类。CPU 按需推理，完成后释放模型引用；不会自动联网下载。缺模型时仍可手画蒙版／走向，关闭“内置深度”和摩尔纹即可渲染基础纹理；也可接同尺寸、近处较亮的灰度 depth IMAGE。内部深度用于按深度亮点、自动隔开线和摩尔纹。

## 原有两节点工作流

1. 在节点菜单搜索“丝袜纹理”，添加“引导编辑”和“渲染”。
2. 原图接引导编辑；其“原图”“部位蒙版”“引导数据”分别接渲染的 `image`、`mask`、`guides_json`。后者可右键转换为输入。
3. 首次运行一次，再点“编辑丝袜引导”。用多边形圈选左腿等部位，按住鼠标画横纹走向；有折叠交界时补隔开线。每个部位至少一条走向线。
4. 保存引导并再次运行。成品和透明纹理图层都可直接接 `SaveImage`；查看“问题标记”与“处理说明”了解未处理区域。

编辑数据随工作流保存。重新加载工作流后，先运行引导节点获取图像预览，再继续编辑。换图尺寸后需重新绘制引导，不自动拉伸旧坐标。批量使用相同引导，编辑预览显示第一张。

透明纹理图层用于叠在 RGB 底图上。原图自带透明度时，成品保留原 alpha；单独纹理层叠到透明底图后，还需要恢复原图 alpha，才能保持相同透明度。灰度 MASK 会同时渐弱织纹和亮点。

外接 MASK 为可选约束，**白色 1=应用，黑色 0=保持**。普通 RGB 图片的 `LoadImage` MASK 通常全黑，不需要接入；透明图片的 MASK 是反向 alpha，若想选不透明区域须先反转。没有外接蒙版时，使用编辑器圈出的部位。

“问题标记”：红色为高频纹理减弱，蓝色为颜色排除，黄色为缺少有效走向。强度只调纹理，亮点单独调；界面手动调强度会自动关闭“自动强度”，API 调用须显式设 `auto_strength=false`。先完成超分，再添加纹理。

新建节点的“按亮部加亮点”默认为 100%，与原工具一致；已保存的 0 不会被改写。“暗部织纹适配”默认开启，使细线、针织、斜单线在近黑布料上仍有可保存的纹理，保留抗摩尔纹与原画明暗，纯黑仍为黑色。关闭它可对照原版暗部衰减。近黑纹理仍可能较淡，可从密度 65%、手动强度 160% 开始按图调节；缩小预览会平均掉细纹，请同时看 100% 局部。

“处理说明”包含实际采用的强度、8 位成品变化像素数和减弱／排除数量；有效区域有求解但 8 位无变化时会明确提示。强度为 0 只关闭织纹，若要完全透传，亮点也需设为 0，并关闭摩尔纹。

## 可选深度与边界

原“渲染”节点的外接深度使用等尺寸灰度 IMAGE，选择“近处较亮”或“近处较暗”。开启按深度亮点、自动隔开线或非零强度摩尔纹时必须接深度；基础功能全程 CPU。新增可选输入 `moire_on`、`moire`、`moire_area` 位于旧输入末尾，保留旧工作流参数位置。

只复用当前 ComfyUI 的依赖；不会在导入期安装或替换 Torch、OpenCV 等。油光是试验功能，合成样例测试不代表任意插画画质。颜色排除可能误排薄丝袜透肤区域，可关闭后对照。

完整编辑器已接入以上原版编辑功能。对照原版时，统一图像、部位蒙版、走向、深度、颜色排除、全部纹理／亮点参数，并关闭暗部适配；种子保持原版 20261005。三张真实测试图的六样式整图、原尺寸裁剪、缩略／裁剪问题图均逐像素一致，三图实际 SAM 三档候选与深度也一致。原有渲染节点仍限制选区外变化，边缘契约与完整编辑器不同。批量套用相同引导不会自动适应另一种姿势，换姿势需要重新标注。

白色屈腿、黑色交叉腿、近黑站姿已用现有图片对照；红／蓝／紫和遮挡／折叠另有合成控制。纯黑无织纹、过密淡出和小图深度墙漏检仍是边界，颜色控制通过不等于所有真实彩丝图片已验收。完整功能表与验收范围见技术说明。
