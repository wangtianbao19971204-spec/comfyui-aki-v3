# ComfyUI 丝袜纹理

在已完成的插画上添加细线、针织、斜单线、加濑风或试验油光纹理。圈选部位、画几条横纹走向线，再调密度和强度；不加载扩散模型，也不需要额外模型下载。

核心算法来自 [silvermoong/stocking-texture-tool](https://github.com/silvermoong/stocking-texture-tool)，固定来源与 SHA 见 [UPSTREAM.json](UPSTREAM.json)，保留 [MIT 许可](LICENSE)。没有移植原桌面服务、安装器或自动保存目录。

## 使用

1. 在节点菜单搜索“丝袜纹理”，添加“引导编辑”和“渲染”。
2. 原图接引导编辑；其“原图”“部位蒙版”“引导数据”分别接渲染的 `image`、`mask`、`guides_json`。后者可右键转换为输入。
3. 首次运行一次，再点“编辑丝袜引导”。用多边形圈选左腿等部位，按住鼠标画横纹走向；有折叠交界时补隔开线。每个部位至少一条走向线。
4. 保存引导并再次运行。成品和透明纹理图层都可直接接 `SaveImage`；查看“问题标记”与“处理说明”了解未处理区域。

编辑数据随工作流保存。重新加载工作流后，先运行引导节点获取图像预览，再继续编辑。换图尺寸后需重新绘制引导，不自动拉伸旧坐标。批量使用相同引导，编辑预览显示第一张。

透明纹理图层用于叠在 RGB 底图上。原图自带透明度时，成品保留原 alpha；单独纹理层叠到透明底图后，还需要恢复原图 alpha，才能保持相同透明度。灰度 MASK 会同时渐弱织纹和亮点。

外接 MASK 为可选约束，**白色 1=应用，黑色 0=保持**。普通 RGB 图片的 `LoadImage` MASK 通常全黑，不需要接入；透明图片的 MASK 是反向 alpha，若想选不透明区域须先反转。没有外接蒙版时，使用编辑器圈出的部位。

“问题标记”：红色为高频纹理减弱，蓝色为颜色排除，黄色为缺少有效走向。强度只调纹理，亮点单独调；界面手动调强度会自动关闭“自动强度”，API 调用须显式设 `auto_strength=false`。先完成超分，再添加纹理。

新建节点的“按亮部加亮点”默认为 100%，与原工具一致；已保存的 0 不会被改写。“暗部织纹适配”默认开启，使细线、针织、斜单线在近黑布料上仍有可保存的纹理，保留抗摩尔纹与原画明暗，纯黑仍为黑色。关闭它可对照原版暗部衰减。近黑纹理仍可能较淡，可从密度 65%、手动强度 160% 开始按图调节；缩小预览会平均掉细纹，请同时看 100% 局部。

“处理说明”包含实际采用的强度、8 位成品变化像素数和减弱／排除数量；有效区域有求解但 8 位无变化时会明确提示。强度为 0 只关闭织纹，若要完全透传，亮点也需设为 0。

## 可选深度与边界

深度使用等尺寸灰度 IMAGE，选择“近处较亮”或“近处较暗”。只有开启按深度亮点／自动隔开线时才必须接深度；基础功能全程 CPU。上游的 SAM 点选、PSD 导入导出和笔刷蒙版暂未接入，可使用其他节点生成 MASK。

只复用当前 ComfyUI 的依赖；不会在导入期安装或替换 Torch、OpenCV 等。油光是试验功能，合成样例测试不代表任意插画画质。颜色排除可能误排薄丝袜透肤区域，可关闭后对照。

这不是原软件的完整替代：还没有区域拆分／合并、镜像走向、擦除自动墙、PSD 亮点图层和原版实时分屏预览。对照原版时，统一图像、部位蒙版、走向、深度、颜色排除、全部纹理／亮点参数与种子 20261005，并关闭暗部适配。此时已测有效选区内一致；原版油光等样式在选区外留下的少量变化会被插件截住，因此不能保证整张图逐像素相同。批量套用相同引导不会自动适应另一种姿势，换姿势需要重新标注。

白色屈腿、黑色交叉腿、近黑站姿已用现有图片对照；红／蓝／紫和遮挡／折叠另有合成控制。纯黑无织纹、过密淡出和小图深度墙漏检仍是边界，颜色控制通过不等于所有真实彩丝图片已验收。完整功能表与验收范围见技术说明。
