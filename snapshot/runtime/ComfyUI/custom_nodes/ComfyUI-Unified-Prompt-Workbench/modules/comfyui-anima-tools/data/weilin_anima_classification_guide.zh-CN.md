# WeiLin -> Anima 分类底线

版本：2026-08-24.marked-integration-v1

## 总原则

每条预设只按一个“主要复用用途”归类。参考页章节只说明原作者当时放在哪里，不能覆盖标题和 tags 明确表达的主要用途。

判断证据顺序：

1. 标题直接表达的用途。
2. 加权、重复或成组出现的核心 tags。
3. tags 组合所表达的完整意图。
4. nai4.top 参考页章节。
5. 当前旧分类。

## 四个根目录

### 角色

底线问题：去掉服装、动作和背景后，这条预设仍然明确回答“是谁或是什么”吗？

归入：不可替换的作品角色、种族、物种、人工生命、稳定身体形态、明确人设身份、人物转化。

不归入：只有制服或穿搭、只有动作或体位、只有场景、只因完整提示词中偶然出现一个人物标签。

### 服装

底线问题：把人物身份替换掉后，这套衣物仍可独立复用吗？

归入：成套服装、制服、地域与时代服饰、内衣泳装、特殊材质、服装改造、配饰、通用 cosplay。

不归入：不可替换的具体角色、只有裸体或身体部位、服装只是在动作串中偶然出现。

### 姿势

底线问题：主要价值是在“做什么、如何互动、身体如何安排或展示”吗？

归入：动作、表情、互动、战斗、体位、拘束姿态、动作情境、以身体展示为目的的构图。

不归入：只有裸体、性别、物种或身体部位；只有衣物破损；只有地点、画风、镜头或质量词。

### 背景

底线问题：去掉人物后，地点、环境、天气、时段或独立场景仍然成立吗？

归入：室内外、自然、城市、幻想、科幻、恐怖环境、天气时段、节庆场地、独立成人场所。

不归入：仅含 `indoors` 或 `outdoors`；主要内容是人物互动；纯镜头、打光和画风。

## 角色与服装的裁决线

- `护士服`、`军装`、`侦探套装`：服装。
- 以护士、军人、侦探的人设身份为主体，衣服只是附带：角色。
- 通用角色扮演服：服装。
- 角色名或作品身份不可替换：角色。
- “某角色穿某套皮肤”标题的复用重点是皮肤或穿搭：服装；重点是召唤该角色：角色。
- 魔法少女“身份”是角色；魔法少女“服装模板”是服装。

## 禁止项

- 不建立正式的“其他、杂项、万能”终点。
- 不把混合全套提示词仅凭原章节整批塞入四类。
- 不复制同一条提示词到多个根目录。
- 纯画师、画风、质量、镜头和生成参数不进入 Anima 四类。
- 年龄边界不明且同时含成人内容的条目进入独立复核区。

## 低置信处理

- 角色与服装证据接近：`待归类/Anima复核/角色服装冲突`。
- 一个标题同时承担人物、服装、动作和场景：`待归类/Anima复核/混合全套`。
- 证据不足：`待归类/Anima复核/低置信`。
- 纯画风、质量或镜头：`待归类/Anima复核/画风质量镜头`。
- 年龄与成人内容边界风险：`待归类/Anima复核/年龄与安全风险`。

## 精细复核布局

- 上述两个分类名是新导入条目的暂存入口；完成复核后，不再长期保留成一个数百条的大桶。
- 原正太萝莉条目不保留独立文件夹，而是按主要复用含义分散进入现有角色、姿势、服装和背景叶子。
- 这批条目的卡片标题统一加 `正太萝莉-` 前缀，用于识别来源；它们会参与对应 Anima 分类的浏览、随机选择和调用。
- 标题前缀只承担来源标记，不参与语义落点判断，也不会改写提示词正文、预览图或条目 ID。
- 只有同时出现年龄信号与成人内容或成人来源的条目留在年龄安全区；单纯年龄设定按角色、姿势、服装或背景的主用途进入 Anima。
- 画风质量镜头长期按画师、媒介、质量、负面词、镜头光影与界面特效拆分，始终不进入 Anima 四类。
- 两组精细复核分类在 WeiLin 共享预设库侧栏置顶；每个叶子保持不超过 200 条。

## 参考页的使用方式

- 常规法典中的 `中外经典` 是角色/种族模板，不是服装。
- `未来科幻`、`魔法特辑`、`野族传说`、`运动人员`、`非常规职业` 原页主要是服装模板。
- 成人法典上册主要用于动作、体位、互动和身体构图。
- 成人法典下册同时含服装、拘束、异种互动、重口动作和人物模板，必须按标题与 tags 拆分，不能整页继承目录。
