## 使用方法

进入完整编辑器的「纹理」页，点顶部「+」增加纹理，最多四层。点图层页签分别调样式、密度、斜度和强度，页签上的 × 删除该层。「融合」中的自动 100% 开启时，各层按比例共同占 100%；关闭时，各层独立设置份额，合计可以低于或超过 100%。两套数值切换后仍保留。

先保存为预设，再点「导出…」下载小型 JSON 文件；「导入…」选择该文件可交换全部层设置。同名导入会追加 `(2)`、`(3)`，不会覆盖已有预设。文件上限 256 KiB，当前 ComfyUI 用户单独保存。纹理页撤销／重做与引导页分别记录，连续一次滑块操作合并为一步；颜色排除归入纹理历史。

## 本地适配与修复

- 暗部适配改为逐层调用原版混合渲染，亮点和摩尔纹仍在混合后各叠一次，采用首个实际绘制层的亮点配方。
- 上游全图缓存键遗漏首层 `amount`，仅改该值可能复用旧图。本地每次渲染使用独立 facade 缓存，编辑器缓存包含完整参数和暗部开关；不改原始上游文件。
- 浏览器文件选择和同源下载替代桌面文件对话框，最多保留 16 份会话内预设下载，不新增服务器文件写入或导出清理范围。
- 在上游范围裁剪前校验非有限值，阻止 Infinity 被裁成合法上限后保存；保留空 layers 查询兼容。非法输入不会修改文档、历史或偏好。
- 新图采用用户最后一次自动 100% 偏好，已保存工程继续使用自身设置。schema 2、旧预设、草稿及素材引用保持兼容。PSD 仅保留已有引导保存能力，本轮不包含上游已撤回的纹理设置嵌入。
