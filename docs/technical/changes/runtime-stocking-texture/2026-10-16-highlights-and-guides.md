## 使用与兼容

保留现有「丝袜纹理修复」工作流及 UAP 放大后入口。打开完整编辑器，在「纹理」页向下找到「高光粒子（试验）」并开启，调整其强度；关闭后移除该效果。它可叠在现有样式和最多四层混合之上，默认关闭。作者已撤回通用白丝高光支持，浅色区域的效果不作此承诺。

「纹理减弱」默认开启，密集纹理会渐弱以降低混叠；关闭会保留密集处的纹理，可能出现更明显的摩尔纹。高光粒子、纹理减弱和原摩尔纹开关均进入现有纹理撤销、预设和 schema 2 工程保存。旧工程缺新键时自动使用粒子关闭、渐隐开启，不改文件、接线、模型、种子、参数或引导。

手绘走向线现在先提取平滑中心线，再进入作者求解。CPU 与 CUDA 均使用同一固定版原始算法；本地只替换既有稀疏求解、近邻和等值线后端。摩尔纹面积从每个鼓起顶部向外展开，内圈保持位置；正常渲染中混合后按摩尔纹、高光粒子、亮点的顺序各应用一次。

## 本地适配

- 逐层渲染 facade 接收并传递新 `fade` 参数，暗部增强的三种织纹与其余样式均遵守开关。
- 带种子引擎为粒子生成独立随机场，保留旧样式的随机数顺序；不扩展旧节点接口。
- 查询字符串的 `particle_on`／`fade` 使用作者布尔语义；强度等数值仍在裁剪前拒绝非有限输入。
- 恢复已存工程时，不可读的纹理设置回退默认，图片、部位和走向继续打开，输入记录不回写；在线修改和预设导入仍严格拒绝非法设置。
