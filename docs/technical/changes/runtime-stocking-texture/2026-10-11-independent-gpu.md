## 行为与边界

`guide_solver.py` 与 `gpu_contours.py` 在可用 CUDA 上执行稀疏求解、批量等值线和近邻计算；拓扑、折线装配和 OpenCV 部分保留在 CPU。`studio_document.py` 适配上游工作线程，设备切换使旧求解失效，保留蒙版与编辑历史。GPU 缺依赖、队列忙、显存不足或数值检查失败时回退原始 CPU 算法，UI 显示实际设备与原因。每次求解使用独立 CuPy 池并释放。

完整编辑器顶部默认 GPU，可切换 CPU，同时控制 SAM、内置深度和走向。SAM/深度每次推理后移回 CPU；最后一个活动页面离开或关闭时清空模型及图像特征，有在途推理则延后释放。多页面序号和租约避免乱序消息误激活，异常断开约 60–75 秒回收。保存的草稿、输入素材、计算完成的深度与磁盘模型不受缓存释放影响；进程 RSS 或 CUDA 上下文内存归零不属于承诺。

保留 Issue #3 的 seams/snap 透传、请求字段防漏测试、7 天临时文件保留策略、固定原始 blob、版本来源和 Windows LF。导出白名单增加六个 GPU 实现／依赖／测试文件；三张已批准展示图保持原哈希。本轮新截图、模型、输入图片和工作流留在仓外。
