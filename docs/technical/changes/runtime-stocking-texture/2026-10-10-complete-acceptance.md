本轮独立原版测试 **114 通过、51 跳过**。跳过原因是作者未公开的 `sample.png`/`sample-guides.psd`，没有伪造原样图或把跳过记为通过。新增 `tests/feature_acceptance.py` 在隔离 aiohttp 实例经真实 HTTP 执行 **51 项**操作/参数/导出/持久化检查，编辑状态和解算/渲染对照独立上游。前一轮真实图、SAM/深度及 912 个颜色/姿势控制的证据继续独立引用，不重复命名为本轮新跑。

以下是明确差异和覆盖边界：

- 逐像素原版对照要求相同原图、蒙版、走向、隔开线、深度和参数，并关闭插件附加的“暗部适配”。开启附加增强后的结果有意不同。
- 安装/更新、独立进程关闭、桌面拖图启动、原生路径保存和“文件夹中显示”由 ComfyUI 的插件安装/服务及浏览器上传/下载替代。插件按需 CPU 推理，与原版自动选择 GPU 的速度不同。
- 完整编辑器单图、最多 2400 万像素、32 部位、4 会话、24 MiB 项目；旧两节点保留批量与软蒙版接口。模型不自动下载。
- 白丝弯腿、黑丝交叉腿、近黑站姿是真实图覆盖；其他颜色/几何为控制样例。任意新姿势与复杂花纹仍需正确标注，SAM 可能需画笔修边，纯黑与过密纹理保留原算法限制。
- 未取得作者私有样图、任意第三方复杂 PSD/PSB 的全面兼容性和所有真实服色/姿势的画质证明。全功能核验不等同于这些输入全部保证一致。

部署与本轮原始证据哈希见 `docs/receipts/stocking_texture_complete_20261010.json`；前轮模型与真实图对照见 `docs/receipts/stocking_texture_studio_20261010.json`。
