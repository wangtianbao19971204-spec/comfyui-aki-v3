日期：2026-10-10。固定上游为 `silvermoong/stocking-texture-tool@6c0c620d1bfa6a2c2691cb2313e928d9c7244ee5`。

## 真实弯腿工作流

在隔离 ComfyUI 8197 的上游投稿候选中，打开既有白丝弯腿真实原图与选区，实际绘制小腿走向；沿膝盖折叠处切开，分别为大腿和小腿绘制走向。撤销回单部位后，再沿接触处绘制隔开线，并添加大腿与膝盖弧形走向。不是直接注入最终求解字段，也不改变生产 UAP。

`tests/bend_acceptance.py` 独立读取三个阶段的项目 schema，使用独立上游 Document 重建，比较五个解算字段与六种样式。18 组渲染逐像素一致，切分前后选区并集不变；共同有效解算区 113728 像素中，切分调整有 31792 像素转向超过 15 度，隔开线/膝盖弧线调整有 43936 像素超过 15 度。这证明走向实际发生变化，不等于所有姿势均达到美术最优。

在编辑器选择线圈、密度 65、自动强度、四类亮点关闭、暗部适配关闭，点击应用并在 UI 运行独立 Studio → SaveImage 工作流。任务 `b3d595f2-4553-4c65-922f-a089d60cfc03` 成功；成品与原版同状态参考逐像素一致，透明图层叠回原图最大误差为 0。三个阶段、原图、18 份成品、工作流、执行历史及界面截图留在仓外。

完整 Studio 保留原版边缘行为；本例油光有 334 个选区外像素变化，不能套用旧节点严格保护选区外像素的结论。SAM 选区并不等于人工真值：交叉腿仍可能漏选或包含鞋/人物，需画笔修边与切分。原始插画不随公开提案分发。

同时登记前轮已用于三图对照图板的 `tests/visual_review.py`：接受调用方的原图、引导、模型验收结果与字体，重新计算独立原版参考，再输出带明确标签的选区/成品/200% 局部图板；不锐化或增强对比度。该工具与真实图板仅留在本维护范围，不在 38 文件上游导出清单内。
