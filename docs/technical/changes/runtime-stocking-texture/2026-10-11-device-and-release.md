# CPU / GPU 选择与离开编辑器后释放模型

日期：2026-10-11。

完整编辑器顶部新增“计算设备”，默认 GPU，也可选择 CPU。选择保存在当前用户的 `stocking_texture/preferences.json`，不写入工作流或改动蒙版、走向线、纹理参数。它控制 SAM、内置深度和完整编辑器的走向求解。切换时重新求解走向，并丢弃旧设备尚未完成的结果；已有深度图仍可复用。原有 Guides/Render 节点保持原接口。

`studio_document.py` 适配作者的后台文档工作线程；`guide_solver.py` 为每次任务创建独立的原算法命名空间。CUDA 执行稀疏 Cholesky、批量等高线提取和最近邻查询；区域拓扑、折线连接、OpenCV 操作及等距邻点的原版判定留在 CPU。没有修改固定上游 `vendor` 的文件或全局函数。界面显示走向实际运行在 GPU 或 CPU，以及回退原因。

GPU 仅在 ComfyUI 生图队列空闲、可用显存足够时借用。任务使用自己的 CuPy 内存池，结束后同步并释放；不卸载生图模型。数值残差失败、依赖缺失、显存不足或队列忙时，释放 GPU 使用权后用完整原算法在 CPU 重算。CPU 选择不会探测或借用 CUDA。首次使用 CUDA 后端需要初始化库和编译内核，速度不能用首次耗时代表暖机耗时。

## 可选依赖

SAM/深度沿用 ComfyUI 的 PyTorch，不新增模型。CUDA 13 环境的走向后端可使用插件内 `requirements-cuda13.txt`；用 ComfyUI 的 Python 安装，勿同时安装多个 CuPy CUDA 发行包。当前验证组合为 PyTorch 2.9.1+cu130、CuPy 14.2.0、CUDA runtime headers 13.0.96、Numba 0.63.1。其他 CUDA 版本需选择匹配的 CuPy/runtime 组合并独立验收；缺失时显示 CPU 回退，插件不会自动安装、下载模型或更改全局环境变量。

## 内存生命周期

- SAM/深度每次推理后移回 CPU，释放 PyTorch 未使用的显存块；活跃编辑期间缓存两种模型与最多四份 SAM 图像特征。
- 关闭编辑器、隐藏浏览器标签页或承载编辑器的面板时，上报页面离开。最后一个活跃编辑器离开后清空 SAM、深度、处理器和图像特征缓存。多个编辑器同时使用时不会互相卸载。
- 推理还在运行时标记待释放；等最后一个模型任务结束再清理，包括离开后才写入的缓存。期间重新进入的编辑器可以继续复用缓存。
- 每个页面有独立标识和递增序号，过期消息不会覆盖更新的离开状态。活跃页面每 15 秒续约；断网、浏览器崩溃等未能发送离开通知时，60 秒租约到期后由每 15 秒执行的回收器清理。
- 草稿、蒙版、已算好的深度图、模型磁盘文件不随卸载删除。重新点选时按需加载模型。进程的 Python/PyTorch/CUDA 库、驱动上下文及通用内存分配器仍可能保留内存；清理专用模型不代表进程内存降为零。

深度模型按固定架构在 CPU 正常构造，再严格装入本地 safetensors；不使用会临时修改全局参数注册方式的 Transformers meta 初始化。这样离开后同时重新载入 SAM/深度时不会把 SAM 参数意外建立在 meta 设备上。并发冷加载实测通过，深度图与此前验收的 FP32 结果逐像素相同。

## 验证与范围

相关合同覆盖 CPU 选择、GPU 忙/低显存/OOM 回退、设备切换期间的结果失效、多编辑器、推理中离开、重新进入及租约过期。可选 `STOCKING_TEST_CUDA=1` GPU 测试覆盖 126 组等高线条件（包括遮罩角点、鞍点、精确顶点、闭环），以及无引导、空洞、分离区域和遮挡墙；成功任务的专用 GPU 池使用与保留字节均归零。

真实交叉腿输入比较六种样式，并进行隔离 HTTP/浏览器点选、设备切换、深度、离开/返回和关闭验收。模型对象回收另以实际权重和弱引用检查，不能仅用 API 缓存数量宣称卸载。具体测试、像素差与源码哈希见[隔离验收收据](../../../receipts/stocking_gpu_guides_20261011.json)，生产状态独立记录。未重复生成图片或更改正式工作流；既有作者功能矩阵只在未变代码哈希匹配的范围内复用。Numba 仅在进程内缓存编译结果，不向插件源码目录写入运行缓存。
