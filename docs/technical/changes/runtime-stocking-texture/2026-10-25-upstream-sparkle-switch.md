## 本地适配

- 原渲染节点没有开关控件。`nodes.py` 在参数里固定 `sparkle_on`，三个亮点滑杆仍是它唯一的开关，节点接口、默认值与接线不变，既有工作流无需改。
- 完整编辑器里 PSD 手绘「亮点」层继续直接生效：`studio.base_params` 的手绘分支固定开启。
- `studio_store.clean_look` 只在缺少 `sparkle_on` 键时，按「任一亮点量大于 0 即开启」迁移旧草稿与旧预设；键存在时严格尊重开关，新界面的关闭状态不会被迁移改写。上游自带默认关闭，不会自动给新工程加亮点。
- 作者服务端的 MIME 修复只作用于其独立服务器；本插件编辑器的静态资源一直使用显式 MIME 表，行为不变。
