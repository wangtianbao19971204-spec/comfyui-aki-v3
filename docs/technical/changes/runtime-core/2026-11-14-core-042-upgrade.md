# 2026-11-14 本体升级 0.33.0 → 0.42.0

## 改了什么

- `snapshot/runtime/ComfyUI/` 由 0.33.0 源码整体替换为 **0.42.0**（887 个文件新增或变化，7 个文件删除），范围只含本体源码；`custom_nodes/`、`user/`、`models/`、`input/`、`output/`、`temp/` 不在本次同步范围内。
- 删除的 7 个文件均为 0.42 已移除的模块：`comfy_api_nodes/nodes_sora.py`、`app/assets/database/queries/{asset,asset_reference,common}.py`、`app/assets/services/bulk_ingest.py`、`tests-unit/comfy_test/seedvr_vae_forward_test.py`、`.gitattributes.upstream`。
- `snapshot/inventory/environment.json` **本次未刷新**：它由 `snapshot.py` 从运行环境 `importlib.metadata` 生成，手工改版本会被 seal 以 `metadata_hash_mismatch` 拒绝。当前清单仍记录升级前的包集（`av 16.1.0`、`comfy-aimdo 0.4.13`、`comfy-kitchen 0.2.31`、前端 `1.49.6` 等），需要时用一次完整 capture 重新生成。

## 为什么

MOSS-Image 只在新核心里有（`moss_image` 文本编码类型、MOSS DiT、Flux2 VAE 路径），0.33.0 的 `CLIPLoader` 没有这个 type，MOSS 只能跑在独立的 0.42 运行时并用 8189 端口。升级后 MOSS 与 Krea2 共用 8188，卸掉第二个运行时、切换脚本和端口歧义。
