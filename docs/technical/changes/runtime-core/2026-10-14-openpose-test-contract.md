# OpenPose 姿势导入测试契约修正

日期：2026-10-14。

整套插件 CPU 审计发现 `ComfyUI-OpenPose-Studio/tests/test_normalize_pose_json.py` 在现行测试后附带了一份旧测试副本。旧副本依赖已删除的 `_MIN_BODY_KEYPOINTS_FOR_VALID_PERSON`，导致 unittest/pytest 导入失败；它还把只有一两个关键点的人物当成碎片删除，与当前实现和文件前半部分的明确契约矛盾。

本轮只移除重复的旧过滤测试，保留既有 COCO-17/COCO-18 格式回归，并补充一关键点、两关键点、混合格式人物顺序及非法数组旁有效人物保持四项检查。数组结构决定标准格式，稀疏人物仍保留原关键点位置；没有重新引入最少关键点阈值，也没有修改 `nodes.py`、运行区插件、人物资料或工作流。

验证为主仓源码的隔离 CPU 测试。GPU 渲染、真实编辑器导入/保存、坐标拖动和姿势库使用需要独立实页证据，不由测试收集和格式规范化成功推断。具体计数与日志由本次 `local/full-suite-audit-20261014` 审计收据记录；不复用旧日志冒充新跑。
