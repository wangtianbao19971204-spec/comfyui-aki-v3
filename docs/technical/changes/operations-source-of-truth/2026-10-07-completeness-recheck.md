## Git 与完整运行实例

| 层 | 保存与恢复边界 |
|---|---|
| Git 源码与文字检查点 | 主仓保存源码、工作流、审查过的提示词／Tag／SQL 分片、模型来源和格式示例 |
| 图库、模型／LoRA和 Python/CUDA | 原图、预览、权重及已安装环境外置；模型按[来源清单](../../../MODEL_SOURCES.md)补确切版本，位置记录不能代替备份 |
| 最新运行数据库 | 在线 DB/WAL/SHM 和应用最新数据保留现场身份；旧 Git 检查点不直接覆盖在线库 |
| 鉴权与私密配置 | API key、Cookie、令牌等单独保护，使用自己的配置；不上传真实值 |
| 历史与回滚档案 | 旧原 Git、bundle、验证和回滚材料按仓外档案保管；可能含敏感原件，不能整目录上传 |

外置不等于隐私分类：模型、LoRA 和环境主要受体积、安装与来源约束；图库、资料和历史是否含个人信息另按内容判断。[外置组合示例](../../../../examples/private-state/README.md)保留占位格式，不是实际资源备份。clone 后仍需补资源、环境和自己的配置，并完成隔离启动与工作流验收，才能搭建完整实例。

仓外组合清单本轮刷新为 v7／398 项：将模型整目录的一条引用拆成 35 条子目录引用，避开新归 Git 管理的 11 份生产架构配置；其余 363 项原登记保留，旧 current 留档。该操作没有复制模型、私密配置或数据库，也没有降低 overlay 层级冲突保护。
