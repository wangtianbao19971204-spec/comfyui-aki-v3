# 2026-10-25 导航栏显存与内存读数

工作台导航栏右端（「图库」之后、「收起侧栏」之前）新增两个读数：`GPU 22.8/31.8G`、`内存 12.2/31.1G`，即「已用/总量」。数据取自 ComfyUI `/system_stats`，与模型加载、队列看到的容量同源，不需要另装监控插件。

## 实现

- `web/system_stats.js` 解析 `system.ram_total/ram_free` 与 `devices[].vram_total/vram_free`；多卡把总量和可用量分别相加，`cpu`/`mps` 条目不当作显存（统一内存机型的 vram 就是系统内存，重复显示会误导）。容量读不到时抛错，界面保留上一次的数值。
- 容量按 1024 进位、保留 1 位小数（31.8G 即 31.8 GiB）；进度条宽度取已用比例；85% 起用 `--uw-warn`、95% 起用 `--uw-danger`，`--uw-warn` 是本次新增令牌，四套主题各一条。数值和进度条同色，`GPU`／`内存` 标签保持 `--uw-muted`。
- 每 2.5 秒轮询；标签页隐藏或工作台被其它弹窗盖住（`offsetParent` 为空）时跳过；点击读数立即刷新；请求 6 秒超时；同一时间只保留一个在途请求。失败保留上次数值并标 `data-stale`，下一次成功清除。
- 打开工作台时挂载，`close()` 调 `dispose()` 清定时器、可见性监听、在途请求与节点。悬停提示含设备名和「来源：ComfyUI /system_stats · 每 2.5 秒刷新 · 点击立即刷新」。

## 布局

- 桌面宽度单行显示：读数在导航右端、「收起侧栏」左侧。开关原有的 `margin-left:auto` 由相邻规则改为 8px，避免两个自动外边距平分空白。
- ≤800px 时读数换到第二行并靠右；导航按钮与开关留在第一行，按钮文字不再被挤成竖排。

## 边界

- 显示的是 ComfyUI 视角的「可用」：`vram_free` 含 torch 可复用余量。本机带 `--cuda-malloc`，PyTorch 的异步内存池只在需要时回收，所以空闲时读数仍可能接近满值（与 `nvidia-smi` 的设备占用一致），不代表模型还在显存里。
- 只显示，不释放显存、不清缓存、不入队、不重启；不读写工作流、提示词、模型、采样或 LoRA 参数。
