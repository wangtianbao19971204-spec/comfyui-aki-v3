# 2026-10-14 控制与擦线一键操作

UAP 的 Anima 原版、Anima 2.9B、Krea2，以及独立生产套件 01/02/03 和模板，共用 `web/control_switches.js` 的控制状态与按钮。独立流程由 `web/control_panel.js` 提供右下角「控制与擦线」入口；UAP 放在常用参数内。加载面板不修改工作流，按钮操作才写原节点控件、mode 与 UAP 分支模式表，不改连接和保存默认值。

## 操作

1. 打开「启用控制」，按需选择「参考图」或「姿势工作室」。所需控制节点和来源自动启用；关闭控制直接选择原模型。
2. 擦线点「画擦线区域」，在原生蒙版编辑器涂抹并保存，再勾「启用擦线」。按钮自动启用参考图控制，不需要进入子图、开分组或换线。
3. 关闭擦线继续使用未擦除的控制图。重新开启不丢弃原遮罩；切工作流或 UAP 分支后，读取该流程保存的状态。

擦线仍需要实际选区：`LoadImage` 的 MASK 是 `1-alpha`，普通 RGB 图没有擦线区域。启用前读取原图 alpha；空选区或丢失图片显示提示，不自动替换用户文件。直接调用前端已有 `Comfy.MaskEditor.OpenMaskEditor`，目标是原遮罩节点，未另建编辑器。

## 执行与状态边界

- Anima 参考控制与 VNCCS 各自独立，VNCCS 没有擦线路径。启用擦线统一切回参考图；选回姿势工作室保留原遮罩但不使用它。
- UAP Krea2 只旁路擦线 Composite 的 destination，不旁路整个控制子图；独立 03 使用原有擦线选择器。擦线关闭保证最终控制图绕过擦除，不保证所有旧预览/遮罩旁支均不执行。
- 来源及原模型选择写入 Dazzle 原控件，按输入名称与显示 label 映射，使用 strict 并清除旧 override。不能因控制输入被静音而悄悄使用原模型。UAP 根节点 mode 同步写 `branches[].modes`，支持字符串节点 ID。
- Anima 关闭控制后用模型节点属性记住上次来源；启用时恢复。其余控件状态来自原节点。擦线高级子图关闭时保留子节点 mode 并静音旁支，开启恢复。
- 启用状态同时核对模型选择器。关闭控制后，仅用旧分组开关打开节点不会显示已接通；需使用新按钮恢复实际控制来源。原有 `(none) + priority` 默认节点模式显示保留。
- 独立面板按节点身份重挂，兼容前端在同一 LGraph 对象上重新加载工作流。异步遮罩检查和编辑器操作核对所有目标身份；删除节点、切流程、替换图片或销毁面板后不能误写旧目标。缺失关键角色的自定义图不显示此面板。
