`snapshot/runtime/benchmark_reports/source_update_flow/` 新增五个参数化入口：`audit_current.py` 保留缺失/null、JSON 类型、正文空格/大小写/权重和数组顺序的原始差异；`fetch_current_images.py` 只在新私有目录抓取新增预览；`stage_current.py` 使用一致 SQLite backup 副本和绑定哈希的人工复核清单构建候选；`publish_current.py` 仅在明确数据范围、唯一服务身份、空队列、来源无漂移和完整回滚备份成立时应用；`accept_current.py` 逐项验证原生 HTTP、来源别名、选择资格、译名、图片与一致数据库副本。
