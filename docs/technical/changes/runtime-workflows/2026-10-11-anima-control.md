# 2026-10-11：Anima 2.9B 姿态控制简化

## 行为与实现

[迁移工具](../../../../snapshot/runtime/production_tools/simplify_anima_control.py)只处理 a29 的姿态和 VNCCS 两个子图，CLI 默认只读；UAP、独立 02 及对应模板共四文件。从 24 节点压缩为 9 节点主视图，原 8 节点擦线/导出链收进高级子图。三条 AIO 线稿加直接深度预处理合成一个 AIO：细致线稿、柔和线稿、漫画线稿、深度图。未选方法不再出现在执行依赖中。

原深度 vitl、1024 分辨率、参考图、遮罩、主强度 1、VNCCS 强度 0.94、时段、模型/LoRA/提示词/种子/采样和主分支默认关闭均保持。迁移拒绝自定义预处理组合；SolidMask 加入原生 value 输入槽，使宽/高链接在当前前端反序列化后仍连接正确槽位。旧 sdscripts 的 preserve_wrapper 参数由原生 clone/patch 机制代替，不做同图像结果承诺。

原生 MODEL_PATCH 加载器读原 controlnet 目录，校验 safetensors 名称、结构和统一补丁启用状态；不复制权重。上游统一补丁原件与提交/哈希一同锁定。只有 2.9B 工作流改原生应用；其他子图逐项保持。

## 界面与执行

常用控制台直接编辑真实子图节点。高级擦线关闭时，对子图做 IMAGE 透传并静音内部节点，避免内部 PreviewImage/SaveImage 被完整 API 导出当成独立输出任务。原模式存入节点属性，保存重载后仍可恢复。参考图上传使用现行本地接口；切换图、分支或销毁面板后拒绝写回旧对象。

## 验证与限制

[收据](../../../receipts/anima_control_simple_20261011.json)记录六项迁移测试、前端行为回归、真实 any-v2 权重 CPU 40 区块路由、独立页面选项/强度/高级入口/擦线两态、原生菜单 Export(API)、Ctrl+S 保存与重载。关闭擦线的导出中高级节点为零，应用图像来自唯一选中预处理；开启时读取组合结果，SolidMask 的 value=0 与宽高链接正确。

隔离环境仅开放 controlnet 权重；底模、编码器、VAE、输入图等未配齐，页面缺资源提示不计作完整流程通过。没有提交采样、下载模型、生产部署/重启或数据库替换。最终预览的实际生成图刷新和画质仍需授权 GPU 用例，旧 LoRA 补丁的历史 A/B 不等于新 ControlNet 的验证。源图中已有的独立 02 旧浏览器接收器保留，不扩展此次改动范围；UAP 继续通过禁用旧接收器的现行校验。
