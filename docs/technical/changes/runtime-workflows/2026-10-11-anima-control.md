# 2026-10-11：Anima 2.9B 姿态控制简化

## 行为与实现

[迁移工具](../../../../snapshot/runtime/production_tools/simplify_anima_control.py)只处理 a29 的姿态和 VNCCS 两个子图，CLI 默认只读；UAP、独立 02 及对应模板共四文件。从 24 节点压缩为 9 节点主视图，原 8 节点擦线/导出链收进高级子图。三条 AIO 线稿加直接深度预处理合成一个 AIO：细致线稿、柔和线稿、漫画线稿、深度图。未选方法不再出现在执行依赖中。

原深度 vitl、1024 分辨率、参考图、遮罩、主强度 1、VNCCS 强度 0.94、时段、模型/LoRA/提示词/种子/采样和主分支默认关闭均保持。迁移拒绝自定义预处理组合；SolidMask 加入原生 value 输入槽，使宽/高链接在当前前端反序列化后仍连接正确槽位。旧 sdscripts 的 preserve_wrapper 参数由原生 clone/patch 机制代替，不做同图像结果承诺。

原生 MODEL_PATCH 加载器读原 controlnet 目录，校验 safetensors 名称、结构和统一补丁启用状态；不复制权重。上游统一补丁原件与提交/哈希一同锁定。只有 2.9B 工作流改原生应用；其他子图逐项保持。

## 界面与执行

常用控制台直接编辑真实子图节点。高级擦线关闭时，对子图做 IMAGE 透传并静音内部节点，避免内部 PreviewImage/SaveImage 被完整 API 导出当成独立输出任务。原模式存入节点属性，保存重载后仍可恢复。参考图上传使用现行本地接口；切换图、分支或销毁面板后拒绝写回旧对象。

## 验证与限制

[收据](../../../receipts/anima_control_simple_20261011.json)记录六项迁移测试、前端行为回归、真实 any-v2 权重 CPU 40 区块路由、独立页面选项/强度/高级入口/擦线两态、原生菜单 Export(API)、Ctrl+S 保存与重载。关闭擦线的导出中高级节点为零，应用图像来自唯一选中预处理；开启时读取组合结果，SolidMask 的 value=0 与宽高链接正确。

以上是初轮 CPU/界面验收，缺少底模等资源的提示当时没有计作完整流程通过。后续用户明确授权实际出图、通过后部署并重启；新证据见 [GPU 与部署收据](../../../receipts/anima_control_gpu_deployment_20261011.json)。源图中已有的独立 02 旧浏览器接收器保留，UAP 继续通过禁用旧接收器的现行校验。

## GPU 验收发现与修复

固定中性提示词、种子 845401323336067、28 步、CFG 3.5、Euler/sgm_uniform，完成无控制基线、四种预处理、擦线以及 VNCCS 浏览器捕获的实际出图。正式流程当前 LoRA 栈为空；本轮不认证任意 LoRA。四种控制图明显约束参考图人物站姿、手与自行车的位置和方向。擦线改变 196593 个控制像素，变化框为半开区间 `[93,513,395,1335]`，擦除内部为黑色。原参考图缩放 1524 的深度模式也完成 1136×1520 输出。

真实运行发现常用面板未主动执行指定控制预览，且现代前端不会及时填充子节点 `imgs`。生成目标现在只追加已启用分支的指定最终预览，面板从原生 `app.nodeOutputs` 取图，并在 `execution_success` 刷新；销毁时移除监听器。不开启高级导出节点。

VNCCS 旧同步只在根图查节点，并在后端使用未清洗的执行 ID 作为文件名。现在按 `1067:111001` 路径从根图逐层定位，后端复用上传 API 的文件名规范。两项 Python 回归和前端路径回归通过；新页面、失效 capture_id、清空预捕获的实际出图中，同步接口返回 200，后端控制图与浏览器捕获逐像素一致。旧失败 history 及旧浏览器模块造成的备用渲染结果均保留，未冒称修复通过。

深度图黑色擦线可能产生额外空间结构，面板明确建议深度关闭擦线；原默认值保持。细致线稿强度 1 在本例遮住眼部，不给通用强度或画质承诺。VNCCS 无浏览器的 Python 备用渲染、SAM3D 图片提取及精细姿态编辑忠实度未认证。

## 限定部署与回滚

部署范围为 22 文件：统一补丁、原生加载器、3 份工作台 JS、VNCCS 两处同步实现、白名单/迁移工具和四份工作流。运行中的工作流按当前原件迁移，保留其他子图、提示词、LoRA、种子、参数和根节点模式。部署前保留逐文件原件/哈希、5 份 SQLite backup API 一致副本、65 份相邻文件摘要以及旧进程/队列身份；只在队列为空时切换并用原启动参数重启。

准确部署和重启后验收以新收据为准；全局 manifest 的 `live_deployed=false` 不用来否认这 22 文件的限定部署，也不改为全仓已同步。回退须成组恢复白名单、代码和工作流；在线数据库未替换，不自动恢复旧 DB/WAL。未下载模型，未合并 PR。
