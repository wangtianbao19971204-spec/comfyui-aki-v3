# 2026-10-11：原版 Anima 控制「参考图 + 匹配提示词」验收

上一轮把参考图（坐姿线稿）与描述站立骑车女性的提示词放在一起，四肢出现退化。本轮保持参考图不变，只改提示词对同一张图的描述，用来区分"控制没生效"和"提示词在描述另一个主体"。

## 用例

隔离实例、固定种子 845401323336067、28 步、CFG 3.5、Euler/sgm_uniform，强度保持生产默认 1，预处理分辨率 1024。控制图用用户提供的线稿 `ComfyUI_temp_oflff_00001_.png`，并把擦线高级子图整体去掉，让完整控制图进入应用节点。

- `pair-matched`：提示词描述线稿本身（深色长发、发饰、褶边裙、前倾抬臂、侧向近景）。
- `pair-mismatched`：同一张线稿，但提示词仍描述上一轮的站立骑车女性。
- `pair-appearance`：姿势与取景同 matched，只把人物外观换成金发蓝眼白裙。
- `pair-canny`、`pair-depth`：matched 提示词下换预处理。
- `pair-erase`：保留已保存遮罩的合成。

## 结果

- matched 与 mismatched 只差提示词：平均绝对差 58.2/50.1/50.7。mismatched 复现上一轮的四肢退化；matched 是同一位深发角色、同一坐姿，结构完整。**退化来自提示词与参考图主体不一致，不是控制失效。**
- appearance 与 matched 平均绝对差 61.1/72.1/61.3：姿势与构图保持，只有发色、瞳色和服装按提示词改变——参考图管姿势，提示词管外观。
- canny 与 depth 在 matched 提示词下分别差 12.6–13.1 与 34.7–36.8，与上一轮"四种预处理产生不同控制图"一致。
- 擦线用例与"去掉整个高级子图"的用例逐像素相同：运行区已保存的遮罩完全不透明，而 `LoadImage` 把单通道图暴露为 `1 - alpha`，所以该合成目前是空操作。上一轮用透明矩形遮罩时擦线确实改变了控制图，即擦线功能本身可用，只是这份遮罩不含透明区。它也不是退化的原因。

## 强度复核

首对运行中强度 1 与 0.63 在同一粒子上曾得到逐像素相同的结果，因此没有把它当作"强度无效"记录，而是重新探查：同一张图在强度 1.0 / 0.8 / 0.63 / 0.4、两个不同种子下各出四张互不相同的图；强度 0.0 与 1.0 的平均绝对差为 36.8–38.9。强度确实进入采样，先前那对相同结果不可复现。

## 边界

单一参考图、单一种子和同一类中性提示词，不构成通用画质认证；线稿结构稀少的区域仍有偏软的位置，本轮不声称强度 1 无伪影。工作流内没有第二路图像条件，因此"姿势参考图 + 另一张外观参考图"的双图方式需要另加模型或节点，本轮未测。
