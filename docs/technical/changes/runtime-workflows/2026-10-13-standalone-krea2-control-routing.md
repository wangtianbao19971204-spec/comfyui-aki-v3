# 独立 Krea2 控制来源与擦线接线修复

## 问题与候选行为

独立 `生产套件_03_Krea2_一体化生产_v2.json` 的编码器 534 原来直接读取 Depth 433。参考图选择器 449 与擦线合成 504 只影响预览；VNCCS Studio 513 也未进入控制编码。因此修改预处理或擦线后，预览可以变化，实际采样仍使用旧 Depth 路径。修复前隔离对照中，独立 03 的控制开启、擦线与 HED 用例编码图及最终图逐像素相同；该证据由本轮主任务的私有验收目录保留。

本次只在主仓正式图和对应模板连接统一路径，复用已安装的原生 `DazzleSwitch`、`DepthAnythingV2Preprocessor` 与 Krea2 编码/应用节点，不增加插件：

```text
参考选择 449 ────────────────────┐
                               ├→ 来源选择 574 → 可选擦线 576 → Encode 534 → Apply 536
VNCCS Studio 513 → Depth 575 ────┘                  ↑
                                           黑色合成 504 + 原遮罩 506
```

来源 574 同时驱动尺寸读取 501 和合成 504 的目标图，使擦除用黑色图随选中来源的尺寸生成。旧连接 587、588、627 保留 ID 并改为读取统一路径，增加连接 663–667。每份图由 99 节点/111 连接变为 103 节点/116 连接。
