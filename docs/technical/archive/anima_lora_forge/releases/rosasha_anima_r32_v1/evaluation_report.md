# 罗莎莎 Anima LoRA v1 审核报告

## 结论

选用 400-step checkpoint 作为 v1。没有继续到 1000 steps，因为 400-step 已通过服装与画风矩阵，
继续训练的主要风险是加强红裙和训练画风绑定。

## 训练状态

- 120 图片 + 120 caption，全部配对并以 `rsrs_anima` 开头
- 无精确重复图、无裸露或 NSFW caption
- BF16，Rank 32，Alpha 16，AdamW，学习率 `2e-5`
- 最终平均 Loss：约 `0.123`
- 峰值显存：约 10.5 GB
- 训练任务返回码：0

## Checkpoint 人工审核

- 100 steps：身份开始形成，体型仍偏高，非成品
- 200 steps：矮小体型明显稳定，进入候选
- 300 steps：发型和头身比进一步接近训练底图，强候选
- 400 steps：身份细节最稳定，服装和画风仍可控，选为 v1

## 五服装矩阵

经典红裙、冒险服、正式礼服、现代休闲、幻想法袍全部正确响应。
五张均保持蜂蜜金发、绿眼、单侧马尾和黑蝴蝶结，没有持续裸露或服装失控。

## 四画风矩阵

动画立绘、水彩绘本、3D 游戏渲染、平涂漫画全部响应成功，人物身份保持良好。
3D 样图曾出现右下伪文字，因此发布负面词增加了 `text, watermark, signature, artist name`。

## LoRA 强度

- `0.6`：身份和矮小比例偏弱
- `0.8`：稳定、可控，适合需要更多底模自由度时使用
- `1.0`：最接近训练底图，换衣和换画风仍正常
- 推荐默认：`0.9`

## 保留项

300-step checkpoint 保留在原运行目录，作为更柔和的备用版本。
完整训练日志、TensorBoard、预览和矩阵均保存在
`runs/rosasha/rosasha_calibration_400_v1/`。
