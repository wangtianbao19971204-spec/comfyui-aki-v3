# WeiLin 分类切换浏览交付记录

日期：2026-07-30

## 交付结果

角色、场景、动作、服装四个 Anima Tags 选择器中的 WeiLin 共享分类树，已由多选复选框改为与原生侧栏一致的整行分类浏览：

- 点击分类整行即可切换当前分类。
- 同一时间只保留一个 WeiLin 分类高亮和筛选条件。
- 点击另一个分类会直接替换旧分类，不再叠加勾选。
- 展开箭头只控制子分类展开/折叠，不会误选分类。
- 选择深层分类时自动展开它的上级路径。
- 保留分类层级、原分类名称和条目数量。

原生的本地大品类、细分特征等过滤器仍维持原有交互；此次只替换 WeiLin 共享分类树。

## 兼容处理

- 旧版缓存中的多个 WeiLin 勾选项会在下次打开时自动收敛为最后一个有效分类。
- 旧版父分类、子分类键会转换为当前完整路径键。
- 恢复共享分类时，会清除与它冲突的收藏分组、Traits 或角色外观维度，避免出现“分类已高亮但结果为 0”。
- 切换回原生分类、Traits 或收藏分组时，会退出 WeiLin 共享分类浏览状态。
