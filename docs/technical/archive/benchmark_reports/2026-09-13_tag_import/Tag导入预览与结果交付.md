## 行为

- 选定 JSON 后只读预览，显示新增、更新、疑似重复、不支持、版本冲突五类统计，主分类与子分类单列。
- 保留原覆盖策略及缺失收藏组归入默认组的明确选项。相同 ID 内容冲突可预览，但未选择允许覆盖时不可提交。
- 确认提交绑定实际转换后的文件内容、覆盖选项、Tag 版本、共享收藏组版本与预览凭据；内容或版本变动需要重新预览。
- 成功保留可读结果并可导出原操作 JSON；已知原子失败保留文件重试；网络结果未知时明确显示未知，不伪称零写入。
- 修复仅改变收藏、备注或收藏组时误算为未变化的问题。预览在内存数据库复用原执行器，原数据库只读；实际写入仍走原事务。
