# 晴空手帖：同图、同布局，三种配色

按用户确认的“白天、夜间、多色”统一三套主题。保留已有保存值 light、dark、anime，仅修改显示名称，已有主题选择无需迁移。

- 白天：清浅纸色、柔和蓝灰点缀，插画较明亮。
- 夜间：石墨灰底、柔和蓝紫点缀，同一张插画降低亮度。
- 多色：同一套插画和图形，增加蓝紫、樱粉与青色的色彩感，明暗继续跟随原生工作流。

三套共用页头插画、13 类功能标识、组件形状、布局、尺寸、间距和交互。工作台、导航、常用控制台、资料库、Tag 卡片、提示词与六种选择器、图库、模型内页使用统一样式。用户资料中的图片不进行调色。

预览页默认打开工作台。顶部“13 类标识”可直接打开资料库并定位总览，分为 7 类页面工具与 6 类选择器。打开预览不再强制重置用户已保存的主题。
