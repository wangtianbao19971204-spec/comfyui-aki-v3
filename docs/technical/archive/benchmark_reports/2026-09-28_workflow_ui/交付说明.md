# 工作流界面统一优化 · 2026-09-28

本批已更新正式插件的 8 个 JavaScript 文件和 1 个共享样式文件。正式服务逐个返回的文件与磁盘版本一致；保存当前工作流后刷新 ComfyUI 即可加载。没有重启服务，也没有提交生成任务。

**状态：前端更新已落地，组件与交互验证通过；真实浏览器视觉验收未完成。** 浏览器通道在两个新页面上持续发生导航和焦点命令超时，尚无可用截图，因此不能把响应式规则已实现等同于窄屏外观已经实际验收。

## 改进内容

| 界面 | 已实现的改进 |
| --- | --- |
| 常用控制台 | 新增按名称查找控制区域、无匹配提示和清除操作；Esc 优先清除查找；LoRA 输入支持 Enter 添加；数值无效时提示并保留原参数；参数区、开关、提示词区采用一致的间距和可伸缩布局。 |
| 统一工作台 | 统一主导航、按钮、状态、输入框、页脚和卡片样式；Ctrl+K 定位全局搜索；侧栏可收起；空值、超界值和整数参数中的小数不会写回原节点。 |
| 资料库 | 提示词卡片的标题、正文、主操作、更多操作和选择状态统一层次；列表视图继续保留；详情侧栏使用同一配色。 |
| 基础 Tag 卡片 | 修复“每页显示 120 条、翻页却只前进 100 条”的重复问题；卡片/列表切换保留已选项；直接复制原文；首次加载与翻页失败可重试，翻页失败保留已有结果；无结果时可清除筛选；修复失效预览的占位显示。 |
| WeiLin 提示词选择器 | 节点内控件和词库弹窗纳入共同视觉风格；词库补充焦点约束、输入标签及焦点返回；Esc 先清空搜索，子编辑器的 Esc 不再关闭底层词库；关闭时取消未执行的搜索。 |
| 角色、服装、姿势、背景、画师、风格质量选择器 | 统一窗口、侧栏、输入框、卡片和编辑按钮；共享卡片支持 Enter/空格选择，编辑按钮不触发选卡；Ctrl+F 定位搜索，Esc 优先清空搜索；角色/画师补充公共弹窗键盘行为；保存失败后显示原因、恢复按钮并允许重试；修复画师卡片鼠标离开时误用初始选择状态的问题。 |

视觉规范集中在 `ComfyUI/custom_nodes/ComfyUI-Unified-Prompt-Workbench/web/studio.css`：石墨色背景、紫蓝强调色、统一边框、圆角、聚焦样式，以及 1050px / 720px 断点和减少动画设置。规则只作用于本次相关工具界面。

## 备份与恢复

运行前文件在 `before/`，逐文件变更在 `changes.diff`。`rollback.py` 默认只核对是否可以恢复，已通过预检。加 `--restore` 后恢复本批修改；若文件已经被后续工作修改，校验会拒绝覆盖。资料和 Tag 数据不在恢复范围内。

```powershell
.\python\python.exe -X utf8 benchmark_reports\2026-09-28_workflow_ui\rollback.py --restore
```

恢复之后保存工作流并刷新浏览器即可，不需要重启 ComfyUI 服务。
