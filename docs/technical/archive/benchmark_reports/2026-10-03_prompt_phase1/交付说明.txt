提示词与工作流优化 · 第一阶段

入口：刷新 ComfyUI，打开“常用控制台”，使用“实际出图提示词检查 → 检查当前分支”。多个启用的顶层 KSampler / KSamplerAdvanced 可分别选择查看，暂不展开子图内部采样器。

本次改动
1. 提示词清洗女仆自动保护 score_7 / score_8_up、LoRA 引用、embedding 标识、__通配符__、引号内原文和已有括号转义。
2. 新增“保留原文”：每行填写一个需要保留的触发词或标识；任意 LoRA 触发词不能从普通标签里可靠猜出。
3. 新增“自然语言 / 编辑指令”模式：原样输出，忽略标签清洗选项。
4. 检查器从所选采样器追溯正负向编码输入，并显示实际模型文件、CFG 负向作用和模型兼容性说明。随机化、清洗节点输出、复杂条件合成等运行时内容明确显示待确认。
5. 只检查实际连线中的 LoRA。关闭和双零强度项不计入；本地元数据异常明确提示，不推断“无需触发词”。选词后预览完整追加结果，确认追加，并可精确撤销；正文、分支或工作流变化会使旧结果失效。

边界
没有修改任何已保存的生产工作流或提示词，也没有把原来只接到展示节点的清洗分支自动接入出图。检查器的结果是点击检查时的快照；修改图后应重新检查。
AnimaYume v1.5 的兼容性提示来自已核对模型说明，并不表示所有原版 LoRA 都不兼容。CFG=1 的提示针对标准 CFG 路径；自定义引导节点和 CFG++ 采样器另行提示。
触发词可能是任选风格、服装或互斥变体，故不自动勾选或全部追加。本轮未进行 GPU 生图和画质对照。

验收与回退
cleaner_tests.json：6 组清洗测试，包含 9 组特殊语法及重复清洗稳定性用例。
inspector_tests.json：16 项 API 图解析测试。
browser_acceptance.json：7 项新页面正式前端验收；中性未保存图，元数据使用隔离响应，写请求拦截，无生成。
FINAL_DELIVERY.json：最终在线状态、后端新增输入注册、真实只读元数据接口、服务资源哈希、81 项正式文件保护、设置保护。
before/：修改前文件；changes.diff：差异；manage.py rollback-preflight：检查回退条件；manage.py rollback：仅在发布哈希仍一致时恢复本次 3 个源码文件。回退后端后需在空队列下重启 ComfyUI。

后续优先项仍按深度审计报告推进：先收敛插件加载范围，再做固定提示词、固定种子的中性场景对照。本阶段不新增插件依赖。
