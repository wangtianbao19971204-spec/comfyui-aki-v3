# 晨星轻量露肩方向 2026-08-18

## Sources Used

- Blue Archive 动画官网角色页: https://sh-anime.shochiku.co.jp/bluearchive-anime/character/
- 学园偶像大师官网: https://gakuen.idolmaster-official.jp/

## Takeaways For Morning Star

- 角色设定要一眼读懂。用少量明确部件建立识别，而不是继续叠袖套、披肩、长后摆、星星挂件和背景声波。
- 晨星的线上形象可以有偶像感，但轮廓应该轻：肩颈线、短裙、腿部和高跟鞋形成主要舞台比例。
- 去掉绿色袖套和覆盖肩膀的绿色肩披，改成端正的露肩偶像上装。露肩只服务于轻盈轮廓，不能走性感化或泳装化。
- 头发必须像角色设定稿一样被管理住：低束、侧束、粗卷束、丝带绑定，发尾自然下垂或贴近身体，不横向飞起。
- 保留的记忆点控制在少数：琥珀眼、暖金发、红色/珊瑚星形发饰、酒红象牙主衣、高跟舞台鞋、少量橘金声波。

## Revised Rule

晨星不是“饰品越多越偶像”。新版底图优先追求清楚、轻盈、可训练：露肩高腰上装、 compact idol skirt、漂亮高跟鞋、受控发束、低背景信息量。绿色只能作为很小的点缀或完全移除，不能再是袖套/披肩的主要大色块。
